About This Forecast

This automated snow ensemble forecasting system combines ensemble members from the NOAA GEFS (Global Ensemble Forecast System) and ECMWF IFS-ENS (Integrated Forecasting System - Ensemble) to provide probabilistic snowfall forecasts for the western United States.


How it works: The system downloads high-resolution forecast data, calculates snow-to-liquid ratios based on temperature profiles, and generates multiple visualization products showing the range of possible outcomes. This approach is inspired by the Utah Snow Ensemble.

⚠️ Forecast Limitations

This system uses a simplified snow-to-liquid ratio calculation based on temperature. It may struggle with "warm nose" situations and cannot reliably identify freezing rain or ice pellets. Always consult official National Weather Service forecasts for critical decisions.

Data Sources & Methodology

  • NOAA GEFS: 31-member ensemble forecast from Dynamical.org
  • ECMWF IFS-ENS: 51-member ensemble forecast from Dynamical.org
  • Snow Calculation: Temperature-based snow-to-liquid ratio (simplified method)
  • Update Frequency: Daily at 12:00 UTC via GitHub Actions
  • Code: Open source on GitHub
